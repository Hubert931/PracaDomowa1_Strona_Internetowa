**Opis projektu**

Strona internetowa poświęcona Hiszpanii. Prezentuje najważniejsze miasta, atrakcje turystyczne, tradycyjne potrawy oraz ciekawostki związane z hiszpańską kulturą.

**Wykorzystane technologie**

- HTML5 – struktura i treść strony.
- CSS3 – wygląd, układ i responsywność.
- JavaScript – interaktywne funkcjonalności strony.
